# Wedwingz — Luxury Wedding Planners & Event Design

> *Crafting bespoke, unforgettable wedding experiences through thoughtful planning, editorial design, and flawless execution.*

---

## 🌟 Overview

**Wedwingz** is a modern, responsive, and luxury-themed website designed for high-end wedding planning and bespoke event curation. Built with vanilla HTML5, modern CSS3, and interactive JavaScript, it offers an editorial aesthetic with micro-interactions, smooth animations, and an intuitive user experience.

---

## ✨ Features

- **Editorial Hero & Navigation**: Elegant sticky navigation with mobile drawer and hero entrance animations.
- **About & Philosophy**: Brand story, founder signoff, and animated milestone metrics.
- **Curated Services Grid**: Full-service planning, bespoke decor styling, destination weddings, venue curation, guest management, and vendor coordination.
- **Featured Portfolio & Lightbox**: Interactive wedding showcase with category filtering, modal view, and keyboard navigation (`ArrowLeft`, `ArrowRight`, `Esc`).
- **Signature Experiences**: Engaging multi-panel showcase of luxury wedding formats.
- **The Wedding Journey**: Step-by-step interactive timeline guiding couples through the planning lifecycle.
- **Love Stories (Testimonials)**: Client reviews and stories with rating stars and testimonial highlights.
- **Destination Showcase**: Destination wedding spotlights (Palace, Beach, Heritage Resort, Secret Garden).
- **Interactive FAQ Accordion**: Expandable questions and answers with smooth transitions.
- **Inquiry & Consultation Form**: Styled reservation and booking form with validation.
- **Accessibility & Performance**: Semantic HTML5 markup, ARIA attributes, keyboard support, and responsive layouts for all screen sizes.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic structure and accessible markup
- **CSS3**: Custom design tokens, CSS Grid, Flexbox, keyframe animations, and responsive media queries
- **JavaScript (Vanilla ES6+)**: Interactive sliders, modal popups, accordion, form handlers, and keyboard accessibility
- **Google Fonts**: *Playfair Display*, *Kumbh Sans*, *Aboreto*

## 🚀 Getting Started

### Prerequisites

Any modern web browser (Google Chrome, Firefox, Safari, Microsoft Edge). No build tools or backend required.

### Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   cd <repo-name>
   ```

2. **Open in browser**:
   - Double-click `index.html` to open it directly in your browser.
   - Or use VS Code's **Live Server** extension.
   - Or run with a local server:
     ```bash
     # Using Python
     python -m http.server 8000

     # Or using PHP (via XAMPP)
     # Place in your htdocs directory and access http://localhost/wed_plan/
     ```
